# Changelog

All notable changes to this project are documented here.

## [0.5.0-beta]

### Added

#### Core package structure
- Modular Python package layout
- Scientific climate data analysis framework
- Automated testing infrastructure

#### Statistical analysis
- Descriptive statistics
- Trend analysis
- Seasonality analysis
- STL decomposition
- Stationarity tests (ADF and KPSS)
- Autocorrelation and PACF analysis
- Cross-correlation analysis
- Spectral analysis

#### Forecasting
- Persistence baseline forecasting
- Mean baseline forecasting
- ARIMA forecasting
- SARIMA forecasting
- Forecast evaluation metrics:
  - RMSE
  - MAE
  - Bias
  - Correlation

#### Visualization
- Time-series visualization
- Forecast visualization
- Statistical diagnostic plots

#### Data handling
- CSV support
- NetCDF support
- Time-series validation utilities
- Resampling utilities

#### Development tools
- Unit test suite
- Ruff linting
- Black formatting
- GitHub Actions continuous integration

#### Examples
- Basic time-series analysis example
- Forecasting workflow example
